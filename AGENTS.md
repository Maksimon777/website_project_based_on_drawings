# Работа над проектом

- Поддерживать PROJECT_MAP.md при каждом запросе, который меняет код, настройки, структуру или рабочий процесс. Обновлять назначения файлов, расположение функций, инструкции редактирования и журнал этапов. Если запрос не меняет проект, не придумывать изменения.
- Каждый собственный файл проекта и каждая папка должны быть описаны в PROJECT_MAP.md. Генерируемые зависимости (.venv), история Git и пользовательские данные описываются по назначению; не перечислять внутренности сторонних библиотек и не раскрывать секреты.
- Объяснять изменения начинающему пользователю на русском языке. HTML и CSS держать отдельно от Python.
- Не публиковать .env, пароли, данные пользователей, содержимое media или виртуального окружения.
- Новые функции разрабатывать в отдельной ветке; для отправки на GitHub использовать явное поручение пользователя. Коммиты должны иметь понятные описания.
- Сохранять правила доступа и переходов статусов заказов. Проверять ошибки, конкурентное редактирование и доступ к чужим файлам.
